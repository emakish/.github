<h3 align="center">The niri desktop for everyone.</h3>
<p align="center">Ready to use and beautiful.</p>

Emaki is an Arch-based desktop built around [niri](https://github.com/niri-wm/niri), the scrollable-tiling Wayland
compositor. The bar, launcher, dock, lock screen and keybindings are already set up, so you install it and start
working. On btrfs, every update can be rolled back from the boot menu.

**Status: late alpha, 0.11.0.** It works on the machines we test on; expect rough edges. Boot it from the USB stick
and try it before you install.
