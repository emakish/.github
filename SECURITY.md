# Security policy

## Supported versions

Only the latest Emaki release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately:

- on GitHub: **Report a vulnerability** in the Security tab of the affected repository
  ([emaki](https://github.com/emakish/emaki/security/advisories/new),
  [packages](https://github.com/emakish/packages/security/advisories/new)), or
- by email: security@emaki.sh

Tell us what is affected, how to reproduce it and what an attacker could do with it.

A problem in an Arch Linux package itself (not in Emaki's own code or packages) belongs to Arch:
https://security.archlinux.org/

## What happens next

You get an answer within 7 days. When the fix is ready, we publish it together with a security advisory and credit
you, unless you prefer to stay anonymous.
